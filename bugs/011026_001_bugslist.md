# New feature

## 1 thêm tính năng di chuyển tab

## 2 thêm phím tắt: sửa hiển thị thêm phím tắt nhỏ tương ứng bên phải (căn phải) của context menu cho tab

- Ctrl + N: thêm tab (phải giữ các connectionid hiện thời tab mới sẽ sử dụng luôn connection)
- Ctrl + W: tắt tab hiện thời (hiện cảnh báo)
- Ctrl + shift + W: tắt tất cả tab (hiện cảnh báo theo từng tab)
- Ctrl + W + right arrow: tắt tab bên phải (hiện cảnh báo)

## 3 Tab context menu thêm

- Pin tab: tab được pin sẽ hiển thị ở đầu. Nếu nhiều tab pin thì hiển thị theo thứ tự được pin
- Open in file Explore: áp dụng cho các file đã được lưu. Mục đích mở nơi lưu file

## 4 taskbar > file: thêm tính năng mở file, hỗ trợ file dạng sql, xml, txt,csv
