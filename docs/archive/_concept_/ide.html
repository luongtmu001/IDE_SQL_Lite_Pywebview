        Query external data sources directly with SQL using virtual tables. Perfect for federated queries across multiple APIs and datasets.

        CREATE VIRTUAL TABLE IF NOT EXISTS table_name USING ext_api(
          'format;https://<url>[;options]',
          'col1 type1, ... ,colN typeN'
        );

        JSON Sources example object | example array
        json;https://url
        Object array: [{"id":1,"name":"John"},{"id":2,"name":"Jane"}]
        Array of arrays: [[1,"John"],[2,"Jane"]]
        (requires all columns defined)

        CSV Sources example
        csv;https://url[;skip_rows[;delimiter_quote]]
        (requires all columns defined)

        DB Sources example
        db;< Group-Name DB-Name >;< sql query >
        (requires all columns defined)

        History Sources example
        hist;< Group-Name DB-Name >;< hist uid >;< page num >
        (requires all columns defined)
